# 画像配置レイアウトアプリ

L判・2L判の用紙サイズに合わせて、複数の画像を自由に配置・トリミングできるブラウザベースのアプリケーションです。
印刷用に高い解像度（300ppi）で画像を出力できます。

## 特徴
- **高解像度出力**: 印刷に適した300ppiでキャンバスを作成・保存します。
- **用紙サイズ対応**: L判 (89x127mm) と 2L判 (127x178mm)、縦横の切り替えに対応。
- **ドラッグ＆ドロップ**: PC画面へのドラッグで簡単に画像をアップロード可能。
- **高機能トリミング**:
    - mm単位でのサイズ指定（即時反映）
    - 切り抜き枠の移動・サイズ調整、ホイールやピンチによる画像の拡大縮小
    - 指定サイズの比率で切り抜き、画像ごとにサイズと切り抜き範囲を保持
- **精密なレイアウト**: キャンバス上の移動は1mm単位でスナップするため、位置合わせが簡単です。

## 使い方

1. **アプリを開く**
   フォルダ内の `index.html` をブラウザ（Chrome推奨）で開いてください。

2. **用紙設定**
   「01 用紙を選ぶ」で用紙サイズと向きを選択します。プレビューに用紙寸法と出力画素数が表示されます。

3. **画像のアップロード**
   - 「02 写真を追加」の「写真を選ぶ」を押してファイルを選択するか、
   - 画面内に画像ファイルを直接ドラッグ＆ドロップしてください（最大4枚まで）。

4. **画像の編集（トリミング）**
   登録された画像の「編集」ボタンを押すと、編集画面が開きます。
   - **サイズ指定**: 幅と高さをmm単位で入力すると、そのサイズ比率で枠が固定されます（1mm以上、0.1mm刻み）。
   - **印刷解像度**: 切り抜き範囲の画素数と指定サイズから計算したppi（縦横の低い方）を常時表示します。サイズ変更・トリミング・拡大縮小に合わせて更新し、250ppi未満はオレンジ、150ppi未満は赤で警告します。警告が出ても編集は確定できます。
   - **再編集**: 画像ごとに確定したサイズと切り抜き範囲が復元されます（ページを開いている間のみ）。
   - **範囲調整**: 切り抜き枠をドラッグして移動・サイズ調整できます。ホイールやピンチで画像を拡大縮小できます。モードの切り替えはありません。
   - **削除**: 「この画像を削除」ボタンで、キャンバスから取り除けます。
   - **決定**: 「決定」ボタンで編集を確定します。

5. **レイアウト調整**
   プレビュー画面上の画像はマウスでドラッグして移動できます。1mm単位でカクカクと動きます。

6. **保存**
   「03 一枚に書き出す」の「PNG」または「JPEG」を押してください。写真を追加すると保存できるようになります。
   ファイル名には日時が付与されダウンロードされます（例: `layout_image_20251215_153000.png`）。
